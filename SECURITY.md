# Security Policy

## Supported Versions

Security updates are handled for the latest public release of Codex Link.

## Reporting a Vulnerability

Please report security issues privately by opening a GitHub security advisory for this repository when available, or by contacting the repository owner through GitHub.

Do not post sensitive exploit details, private backup paths, credentials, or personal data in public issues.

## Data Handling

Codex Link is designed to operate on local files selected by the user. Backup and restore artifacts may contain conversation history, project names, local paths, Skills, configuration files, and other local Codex data. Review restore points before sharing them with anyone.

## Release Integrity

Release assets include SHA-256 checksums. Verify downloaded artifacts against `SHA256SUMS.txt` before installation or distribution.
