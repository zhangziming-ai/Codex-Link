# Codex Link v1.2 更新说明（审核稿）

> 状态：已审核，准备提交并上传 GitHub
>
> 应用显示版本：v1.2
>
> 安装包内部版本：1.2.0

## 一、本次更新目标

v1.2 重点解决备份数量容易误解、恢复点路径在新设备上无法识别、恢复内容无法展开，以及对话无法按项目清晰选择的问题。

恢复时以备份中记录的项目名称、原始项目路径和对话归属进行分组。恢复目标仍是同一个 Codex 数据目录或用户指定的隔离测试目录，不会把项目代码和素材文件复制到新的项目文件夹。

## 二、恢复界面更新

### 1. 按项目名称分组

- “项目记录”下按照项目名称显示项目。
- 每个项目显示原始路径及包含的对话数量。
- 每个项目可以独立展开或收起。
- 展开项目后可以查看并选择项目所属的具体对话。
- 左侧恢复选择区和右侧恢复摘要均采用“项目 → 对话”层级。

### 2. 项目级和对话级选择

- 每个项目增加“全选本项目”按钮。
- 全选后按钮切换为“清空本项目”。
- 保留项目复选框及逐条对话选择。
- 项目部分选中时显示半选状态。
- 选择项目会自动包含对应的线程索引关联。

### 3. 修复展开菜单

- 修复菜单点击后只改变箭头、内容却不可见的问题。
- 取消恢复选择区父容器的固定高度裁剪。
- 展开内容强制参与页面布局，避免被后续菜单覆盖。
- 数量、文字、图标和箭头所在整行均可点击。
- 禁止菜单标题文字被误拖选。

### 4. 修复操作后跳动

- 项目全选、清空后保持当前页面滚动位置。
- 点击项目复选框后保持项目列表内部滚动位置。
- 单独选择或取消对话后保持当前项目和列表位置。
- 展开、收起项目时不再因整块列表重绘而跳回顶部。

## 三、备份范围和数量更新

### 1. 项目与对话范围

- 备份 Codex 数据目录中能够识别的全部项目关联记录。
- 项目可以位于不同盘符、Codex 安装目录之外或普通工作文件夹中。
- 对话按照其记录的项目路径归入项目分组。
- 活跃对话与归档对话分别统计，并在恢复时分别处理。

### 2. 数量显示

- 项目数与对话数分开显示。
- 对话数来自实际备份内容，不再把“无需手动选择”错误显示为“对话 0”。
- 恢复页面明确显示统计来自所选恢复点，而不是当前设备扫描结果。
- 备份与恢复数量不一致时，可以区分当前设备数据和历史恢复点数据。

### 3. 不包含的项目内容

项目记录备份保存项目名称、路径、对话归属和相关索引，但不复制项目目录本身。因此以下内容不属于项目记录备份：

- 项目代码文件。
- 图片、视频、音频等素材。
- 项目目录中的构建产物。
- 未存放在 Codex 数据目录中的普通工作文件。

## 四、新设备恢复更新

- 可以直接选择一个有效恢复点文件夹。
- 可以选择 restore-points 根目录，由程序自动选择最新有效恢复点。
- 可以选择 Codex Link 备份根目录或其上级目录。
- 自动清理复制路径时附带的双引号或单引号。
- 新设备没有本机备份管理记录时，仍可读取外部硬盘或同步盘中的恢复点。
- 支持先恢复到隔离测试环境，再决定是否写入正式 Codex 数据目录。

## 五、可恢复与需重新配置的内容

### 可恢复

- 项目关联记录。
- 活跃对话。
- 归档对话。
- 任务索引及数据库关联。
- 个人记忆。
- 规则与配置。
- 全局规则。
- 本地 Skills。

### 仍需重新配置

- API Key 和其他密钥。
- 第三方 Provider 授权。
- 网站登录状态。
- 插件登录状态。
- 系统钥匙串或凭据管理器中的凭据。
- 跨系统的本地工具路径和部分执行权限。

## 六、安全与恢复保护

- 创建恢复计划前校验恢复点结构。
- 恢复前执行逐文件 SHA-256 完整性校验。
- 正式写入前自动创建本机回滚点。
- 恢复失败时自动回退。
- 支持恢复后验证。
- 支持手动撤销已完成的恢复。
- 数据库恢复默认采用合并方式；完整替换仍需明确确认。
- 检测目标数据库 WAL/SHM 冲突，避免在 Codex 正在写入时破坏数据。

## 七、Windows 与 macOS 同步

### Windows

- 构建目标：NSIS x64 安装包。
- 拟发布文件名：Codex-Link-Setup-1.2.0-x64.exe。
- 应用标题显示：Codex Link v1.2。

### macOS

- 与 Windows 共用本次全部功能代码和版本元数据。
- 构建目标：Apple Silicon ARM64。
- 产物格式：DMG 和 ZIP。
- 拟发布文件名：
  - Codex-Link-1.2.0-mac-arm64.dmg
  - Codex-Link-1.2.0-mac-arm64.zip
- 应用标题显示：Codex Link v1.2。
- GitHub Actions 使用 macos-14 ARM64 环境构建并验证。
- 正式签名、公证和上传 Release 需要仓库中已配置有效的 Apple 签名凭据；没有凭据时只能生成未签名测试包。

## 八、验证情况

当前已经完成：

- JavaScript 语法检查。
- 52 项自动化功能和恢复测试。
- Windows 打包后 Electron 应用端到端测试。
- 34 个项目分组生成验证。
- 一级菜单连续展开/收起验证。
- 项目名称真实可见性验证。
- 项目菜单与后续菜单不重叠验证。
- “全选本项目 / 清空本项目”连续操作验证。
- 项目选择后滚动位置保持验证。
- SHA-256 校验、实际恢复、恢复后校验和回滚验证。
- 打包应用控制台错误为 0。

macOS ARM64 的构建配置、产物名称和验证脚本已经同步到 1.2.0。最终 DMG/ZIP 仍需在 GitHub 的 Apple Silicon runner 上执行，Windows 本机不能代替 macOS 完成原生启动、DMG 挂载和签名/公证验证。
