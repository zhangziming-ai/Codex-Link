# Codex Link v1.1 恢复问题解决清单

## 一、数据口径

- [x] 备份页标明“当前设备扫描”。
- [x] 恢复页标明“所选恢复点”。
- [x] 项目数和对话数分别统计，不再把对话数显示为项目数。
- [x] 当前设备与历史恢复点数据不一致时允许显示不同数量。
- [x] 当前对话与归档对话分别显示，并在项目汇总中合并为恢复点对话总数。

## 二、恢复目录读取

- [x] 自动清理粘贴路径两侧的单双引号。
- [x] 支持选择具体时间戳恢复点目录。
- [x] 支持选择 restore-points 目录。
- [x] 支持选择 Codex Link 目录。
- [x] 支持选择 Codex Link 的上一级备份目录。
- [x] 选择备份根目录时自动读取最新有效恢复点并给出提示。
- [x] 新设备没有本地备份管理记录时可直接浏览移动硬盘或同步盘。

## 三、恢复界面展开

- [x] 移除恢复选择区对原生 details/summary 下拉的依赖。
- [x] 使用独立按钮控制展开状态。
- [x] 使用 hidden 明确控制内容显示与隐藏。
- [x] 项目分组默认展开。
- [x] 项目名称按钮只负责展开，复选框只负责整项目选择。
- [x] 恢复摘要区采用相同的显式展开机制。
- [x] 展开按钮提供 aria-expanded 和 aria-controls。

## 四、恢复范围

- [x] 对话记录可逐项选择。
- [x] 项目选择自动包含该项目下的对话。
- [x] 所选对话自动合并对应任务索引。
- [x] 归档对话、记忆、规则和 Skills 分组显示。
- [x] API Key、登录态和系统凭据保持排除或重新授权策略。
- [x] 项目代码与素材文件明确不属于项目记录恢复范围。
