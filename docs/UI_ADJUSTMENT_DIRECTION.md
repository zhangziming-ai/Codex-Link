## 已完成的 UI 前置能力

- 主备份接口可把分类内容、指定项目/对话、指定 Skills 合并进同一个恢复点。
- 恢复计划会返回恢复点内真实存在的可恢复清单。
- 支持 `recommended`、`all_safe`、`all`、`custom` 四种恢复选择模式。
- 自定义恢复只生成所选条目的写入映射。
- `auth.json` 永久不可恢复；API 仅保存名称和迁移说明，不保存密钥。
- 插件和本地工具默认不选，显式选择后仍要求高风险确认。
- 选择性恢复继续执行 SHA-256 校验、自动回滚、写入后校验和中断恢复。
- Windows 与 macOS 共用恢复点格式和业务逻辑，平台差异由适配层处理。

## 调整方向（按序号确认）

01. 备份页只保留一套选择状态，删除上方勾选与下方精细选择的重复语义。

02. “推荐方案”改为预设按钮，不再作为第二套独立复选框。

03. 增加“自定义方案”，展开后直接编辑唯一的备份清单。

04. 保留全局“一键全选安全内容”。

05. 保留全局“使用推荐方案”和“清空全部”。

06. 全局全选默认不包含插件、本地工具、登录凭据等高风险内容。

07. 每个大类保留“全选本类”和“清空本类”。

08. 搜索后的“全选”作用于全部匹配项，不只作用于当前显示的前 20/60 条。

09. 顶部分类卡与下方详情不再重复选择；分类卡只显示状态、数量和展开入口。

10. 项目、对话、Skills、API、插件、MCP 和本地工具统一使用分类面板。

11. 项目记录支持按项目名和路径搜索。

12. 对话统一命名为“对话记录”，避免“独立对话”被理解为项目外对话。

13. 对话内提供“全部对话 / 按项目 / 按单条”三种查看方式，结果写入同一选择状态。

14. Skills 支持名称、说明、来源和类型搜索。

15. Skills 鼠标悬停或键盘聚焦时显示简短能力说明、来源和迁移提示。

16. API 名称沿用当前扫描到的原始命名，不重新命名 Provider。

17. API 支持 Provider、原名称、功能说明和使用项目搜索。

18. API 悬停或聚焦时显示功能、Provider、使用项目及目标设备重配提示。

19. API Key、Token、登录凭据不进入备份，也不提供高级开启入口。

20. 插件和本地工具放入高风险区，默认关闭。

21. 灰色表示未发现、不可用、被策略锁定或永久排除。

22. 红/珊瑚色表示敏感或高风险，使用浅底色、红色图标与边框，不使用大面积饱和红。

23. 橙色表示跨系统或恢复后需要人工复核。

24. 蓝色表示普通选择和主操作，绿色表示已校验或安全完成。

25. 页面底部只保留一组“预览计划 / 创建备份”主操作。

26. 无论选择多少分类或单项，一次操作只生成一个恢复点。

27. 右侧计划实时显示项目数、对话数、Skills 数、分类数、预计大小和风险提醒。

28. 备份清单记录每个内容项的来源、粒度、风险、目标策略和完整性信息。

29. 恢复页先选择恢复点，再校验完整性，然后显示该恢复点真实包含的内容。

30. 恢复模式提供“推荐恢复 / 全部恢复 / 自定义恢复”。

31. 恢复页保留“全选可恢复内容”和“清空全部”；高风险项必须再次明确选择。

32. 恢复项粒度与备份粒度一致：分类、项目、对话、Skills 和配置文件均可单独选择。

33. 恢复点中没有的内容显示灰色并说明“此恢复点未包含”，不能勾选。

34. 登录凭据显示灰色锁定状态，并提示在官方 Codex 客户端重新登录。

35. 对话恢复采用导入/合并策略，不删除目标端其他对话。

36. `config.toml` 跨系统时进入导入区供人工合并，不直接覆盖目标配置。

37. Skills、规则与配置冲突在执行前展示“保留目标 / 导入副本 / 覆盖”策略说明。

38. 目标系统选择与实际平台适配分离；同一恢复点可用于 Windows、macOS 和 Linux。

39. Windows 与 Mac 使用同一信息架构和设计系统，Mac 仅调整路径、菜单、标题栏、Finder 和 arm64 工具提示。

40. 功能与安全回归完成后再统一做高级 UI：按钮玻璃高光、鼠标跟随反射、轻微抬升、按压回弹、150–220ms 过渡，并尊重“减少动态效果”。

## 创建备份拟调整结构

```text
创建备份
├─ 备份文件夹
├─ 方案：[推荐方案] [自定义方案]
├─ 全局操作：[使用推荐方案] [一键全选安全内容] [清空全部]
├─ 唯一备份清单
│  ├─ 对话记录（全部 / 按项目 / 按单条）
│  ├─ 任务索引与个人记忆
│  ├─ Skills（搜索、悬停说明、分类全选）
│  ├─ 规则与配置
│  ├─ API 接入记录（仅名称和迁移说明）
│  └─ 高风险区（插件、本地工具、登录凭据锁定）
├─ 右侧：实时计划与风险说明
└─ 底部：[预览计划] [创建一个恢复点]
```

## 从备份恢复拟调整结构

```text
从备份恢复
├─ 选择恢复点
├─ 完整性校验
├─ 恢复模式：[推荐恢复] [全部恢复] [自定义恢复]
├─ 全局操作：[全选可恢复内容] [清空全部]
├─ 恢复点内容清单
│  ├─ 仅显示 manifest 中实际存在的项目
│  ├─ 支持分类、项目、对话、Skills 和配置文件选择
│  ├─ 高风险项明确确认
│  └─ 登录凭据永久锁定并提示重新登录
├─ 目标系统与冲突/合并策略
├─ 右侧：恢复摘要、路径映射和风险
└─ 底部：[校验并生成计划] [恢复所选内容]
```

## 推荐实施顺序

1. 调整创建备份的信息架构与唯一选择状态。
2. 接入统一备份接口，删除分类内的独立创建按钮。
3. 调整恢复页并接入选择性恢复清单。
4. 加入搜索、分类全选、悬停/聚焦说明与高风险状态。
5. 完成功能、键盘可访问性、窗口尺寸和跨平台回归。
6. 最后统一玻璃材质、悬停高光和微交互。
