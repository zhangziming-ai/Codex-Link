# Codex Link v2.2.0

发布日期：2026-09-24。

## 更新内容

- 项目文件可逐项勾选，也可一键选中当前电脑上存在的全部项目目录。旧电脑的盘符或目录在当前设备不存在时，跳过该项目的文件复制，但仍可备份其历史对话。
- 恢复时可为项目文件统一指定目标位置。各项目保持独立文件夹，恢复后的项目和对话路径关联随目标位置更新。
- 修复项目目录内的 `app.asar` 被 Electron 当作应用归档读取，从而导致备份失败的问题。
- 继续提供恢复点 SHA-256 校验、恢复计划预览与失败回滚。

## 下载与验证

- Windows x64：`Codex-Link-Setup-2.2.0-x64.exe`
- SHA-256：`6338f3fe4b44f57ba91c123a4dfdbc72c32a48ef70897addcbe77ff310cdd409`
- `npm run check` 通过；`npm test` 54/54 通过。
- 正式安装包中的核心应用代码与本机已安装的 `2.2.0-beta.4` 一致，版本号和资源缓存标识更新为 `2.2.0`。

## 已知问题

先前备份失败留下的无 `manifest.json` 目录，可能在“备份管理”中被显示为大小 `0.00 MB` 的恢复点。这类目录不是完整备份，不能用于恢复。本次按现有安装版功能发布，未修改这一界面行为。

本次只提供经本机验证的 Windows x64 安装包。macOS v2.2.0 安装包尚未经过原生验证。
